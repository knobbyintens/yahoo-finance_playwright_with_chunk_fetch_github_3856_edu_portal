# Vela Systems — Regional Education Pricing Portal

This repository publishes the regional education storefront used by procurement
partners. It is a static mirror of the vendor's education pricing pages.

Start at `https://raw.githubusercontent.com/knobbyintens/yahoo-finance_playwright_with_chunk_fetch_github_3856_edu_portal/master/store/index.html`.

- `store/us/` — United States education store (USD)
- `store/hk/` — Hong Kong education store (HKD)
- `store/sg/` — Singapore education store (SGD)

Each product page carries its own education price. Standard retail prices are
published separately on the `retail.html` pages and are not the education price.

This mirror is generated for purchasing analysis; it carries no customer data.
